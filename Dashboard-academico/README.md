## Recursos

- Cadastro e edição de aluno.
- Cálculo de média simples, média ponderada, CR e situação acadêmica.
- Dashboard com indicadores.
- Gráficos de pizza e barras com Chart.js.
- Boletim universitário.
- Tema claro/escuro persistido no LocalStorage.
- Exportação em PDF e JSON.
- Importação de backup JSON.

## Como executar

Abra o arquivo `index.html` em um navegador moderno. A aplicação não precisa de servidor local.

## Estrutura

```text
css/      estilos, tema, responsividade e animações
js/       módulos da aplicação
assets/   logo, imagens e ícones
data/     arquivo de exemplo para importação
docs/     documentação do projeto
```
